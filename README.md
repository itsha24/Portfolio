# Portfolio Website

My personal portfolio showcasing my projects, skills, and experience in software development.

Static Jekyll site, built to deploy on GitHub Pages via the included GitHub Actions workflow
(`.github/workflows/pages.yml`) — push to `main` and it publishes automatically once Pages is
enabled (Settings → Pages → Source: GitHub Actions).

## Built With
- HTML, Bootstrap 5, and [Jekyll](https://jekyllrb.com/) (for the shared layout/nav/footer via GitHub Pages' built-in Jekyll support)

## Structure
- `_layouts/default.html` — shared page shell (nav, footer, head)
- `index.html`, `resume.html`, `projects.html`, `contact.html` — page content
- `css/site.css` — theme styles
- `pdfs/Resume.pdf` — downloadable resume
